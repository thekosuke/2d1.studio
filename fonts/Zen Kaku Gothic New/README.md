# Zen Kaku Gothic New

Source: Google Fonts, https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew
Designer: Yoshimichi Ohira / Zen Project. License: SIL OFL 1.1 (OFL.txt).
Downloaded 22 October 2026. Official Regular, Medium, Bold and Black TTFs were converted
to WOFF2 using fontTools; glyph outlines and coverage are unchanged.

Served locally through css/japanese-font.css on Japanese routes only.
Optical mapping: CSS 400 uses Medium, 500 uses Bold, and 600–700 uses Black.
These heavier Japanese faces balance Walla; Latin weights remain unchanged.
SC Walla precedes Zen in the stack, retaining its Latin letters and numerals.
Noto files remain in the repository for reversibility but are no longer loaded.

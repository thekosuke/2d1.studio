# Color library

| Name | Hex | Use |
|---|---|---|
| Icon Red | #FF2B00 | Brand, accents, emphasis, selected controls |
| Soft Beige | #FAF0E6 | Main ground; text against Studio’s dark ground |
| Sand Gray | #D6CEC5 | Supporting surfaces and existing focus treatments |
| Sub Gray | #807573 | Supporting text |
| Pure White | #FFFFFF | Form fields and control surfaces |
| Cranberry Brown | #320505 | Primary text, borders, and ink |
| Ash Brown | #191416 | Studio background |
| Rich Black | #16161A | Retained legacy palette color |

Named tokens and existing semantic aliases are defined in css/walla.css. Ash Brown is separate from Cranberry Brown: changing Studio’s background does not change the original ink color. Original artwork/product colors remain intact.

# Image permissions review — 27 October 2026

The provenance audit is complete. **Public publication permission is not confirmed for the current catalog.** No license grant to 2D1 was found in the repository evidence, public policies, or bounded connected/local sources checked (see the connected-source addendum). Existing private grants elsewhere have not been ruled out. This is an evidence inventory, not a determination that each current use is unlawful or that a legal exception applies.

## Coverage

- **107 catalog items**, **492 photo references**, **488 unique referenced local catalog image files**.
- **103 actual source hosts**. Each reference is mapped to its actual photo source, separately from its product-maker/product URL.
- **1,476 total source/delivery files** mapped to those masters (responsive copies do not create a new license).
- **143 current non-catalog HTML image/video/poster references** inventoried separately: portfolio exports, brand assets, owner app icon, AI concept and catalog composites.
- 104 items already contain caveats about unverified rights; three have no caveat: Floyd Cabin Aluminum, Jellycat Amuseables Basketball, and Tobeus Pick Up.
- All referenced catalog masters exist. A valid HTTP URL, large native resolution, transparency treatment, source credit, a downloaded press kit or ownership of the depicted product is not itself proof of a publication license.

## Outcome

- **0 items cleared by an explicit recorded publication grant.**
- **11 items / 45 unique catalog files** contain exact-source or official-site terms saying the proposed public reuse needs authorization or reserves rights without granting reuse. These are labeled “permission required” as the documented permissions route; statutory exceptions and private agreements have not been adjudicated.
- **96 items / 443 unique catalog files** remain “unverified.” This means no grant was verified; it does not mean permissive use.
- The registry supports explicit permission / conditional / permission required / unverified, but no evidence strong enough for the first two was found for this exact publication and treatment. No favorable statuses were invented.

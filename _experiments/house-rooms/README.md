# Inside the blocks — design exploration

Three interactive composition studies for About, 20 October 2026.
Open http://localhost:4173/_experiments/house-rooms/ with the existing preview.
Switch concepts, switch Studio/Shop, and use Lean in to preview the depth.

These are composition studies, not production layouts. Copy is condensed for
comparison. Motion is a depth sketch, not the finished native-scroll journey.
Mobile production would unfold into a vertical reading layout. The final content
must use the exact footer social-links left edge at each breakpoint.

Recommendation: Open face, combined with the adjacent-room passage of Through
the wall. The recommended study was reduced by removing secondary labels and
the display shelf. Keep geometric wall thickness, one image, and readable flat
copy. Unfold the block is more expressive but suggests packaging over habitation.

Production About is unchanged. No deployment or commit.
